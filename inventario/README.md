# Inventário da casa

App (add-on) do Home Assistant para manter o inventário da casa: cômodos, itens, fotos e valores, com relatório para seguro e leitura de fotos por IA.

Abre pela barra lateral do Home Assistant (Ingress), sem senha extra. Os dados ficam em arquivos abertos (JSON e JPG) e entram nos backups do Home Assistant.

Veja a aba **Documentação** do app para instalação, uso e configuração da IA.
